# Habibi Restaurant Website 🍽️

A modern and SEO-optimized restaurant website built for **Habibi**, a local restaurant brand. This project was completed as part of a freelancing engagement and focuses on providing an engaging, responsive, and fast-performing user experience.

## 📸 Demo

[Live Preview][(https://your-live-demo-link.com](https://ravinarada.github.io/Habibi_Restaurant/))

## 🌟 Features

- 🖥️ Fully responsive UI for mobile, tablet, and desktop
- 🛒 Cart functionality for menu items
- 🔍 SEO Optimization (meta tags, sitemap, keywords, performance tuning)
- 🧭 Smooth navigation and animated transitions
- ⚡ Fast load times with lazy image loading
- 💬 Customer testimonial carousel
- 📞 Contact form with validation
- 📍 Google Maps integration for restaurant location

## 💻 Tech Stack

- **Frontend**: HTML5, CSS3, JavaScript , Tailwind CSS / Bootstrap 
- **SEO**: Meta tags, Open Graph, sitemap.xml, robots.txt
- **Hosting**: Hostinger

## 🔨 Functional Modules

- **Home Page** – Hero section, brief intro, and CTA
- **About Us** – Restaurant story and values
- **Menu Section** – Categorized menu with add-to-cart feature
- **Cart Page** – Item listing with quantity update and total price calculation
- **Gallery** – Photo showcase of ambiance and dishes
- **Contact Page** – Map location and feedback/contact form

## ⚙️ Performance & Optimization

- Minified JS and CSS
- Image compression
- Lazy loading for images
- Lighthouse score > 90 (on mobile & desktop)

## 🧩 Challenges Faced

- Ensuring a consistent cart state across menu categories
- Client-specific SEO keyword adjustments
- Optimizing for different screen sizes on a short deadline
